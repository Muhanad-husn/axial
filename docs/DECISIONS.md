| DEC-33 | 2026-07-21 | **Abstention is a per-axis flag on the tag record, never a value in the controlled vocabulary — DEC-31's deferred question, settled.** DEC-31 adopted best-of-N on the blind axes and closed with "what the pipeline writes on abstention is an open design question deferred to that issue, not settled here." Issue #294 (PR #302) settles it: when an axis's `N` draws hold no strict plurality, that axis records `{primary: null, abstained: true, draws: [<the distinct primaries, in draw order>], status: ...}`. **Why a flag, not a sentinel.** The record already carries three closed-vocabulary assertions — a real school id asserts *this school applies*, `not-applicable` asserts *the passage advances no theoretical position*, `unlisted` asserts *a real school applies that this vocabulary misses*.
