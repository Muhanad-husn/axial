# config/briefs/cross/ — the ten cross-book briefs

The answer-measurement set since DEC-76 (#883). The smoke set (`../smoke/`) stays
the pass/fail gate; effects on answers are measured here.

Each brief is built on a cluster of cross-author conflicts in the argument map and
asks a question that needs several books: named accounts set against each other,
never one case. That is deliberate. How many books an answer cites is set by the
question's scope, not by retrieval, so S-04 and S-05 cannot show breadth at all.

| brief | question |
|---|---|
| X-01 | genocide |
| X-02 | civil-war violence |
| X-03 | the European miracle |
| X-04 | oriental despotism |
| X-05 | Syrian and Arab nationalism |
| X-06 | the Ba'th political economy |
| X-09 | war and popular nationalism |
| X-10 | sources of social power |
| X-11 | tribes and the state |
| X-13 | how the Asads held power |

Thirteen were drafted; X-07, X-08 and X-12 were dropped for repeating S-03, S-04/S-05
and S-02. Baseline (kind order + #858, 3 draws): 4.50 sources cited per answer,
6.87 corridor positions cited, both ends cited on 29% of conflict pairs shown.
